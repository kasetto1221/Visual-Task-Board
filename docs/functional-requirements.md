# 機能要件定義書

**プロジェクト名：** Visual Task Board  
**バージョン：** 1.0.0  
**作成日：** 2026年5月8日  

---

## 1. 概要

本システムは、チームのタスクを視覚的に管理するためのWebアプリケーションである。カンバンボード形式でタスクのステータス・期限・担当者を一目で把握でき、チームの生産性・ベロシティを分析するダッシュボード機能を備える。

---

## 2. 利用者

| ロール | 説明 |
|--------|------|
| チームメンバー | タスクの作成・更新・完了を行うエンドユーザー |
| チームリーダー | ダッシュボードでチーム全体の状況を把握する管理者 |

---

## 3. 機能要件

### 3.1 タスク管理

#### 3.1.1 タスク一覧（カンバンボード）

- **FR-T-001** タスクをカンバン形式（未対応 / 進行中 / レビュー中 / 完了）で表示する
- **FR-T-002** 各カラムにタスクカードを表示し、タイトル・優先度・期限・担当者アバターを明示する
- **FR-T-003** タスクカードをドラッグ＆ドロップで別カラムに移動し、ステータスを更新できる
- **FR-T-004** 期限切れのタスクを視覚的に強調表示（赤色）する
- **FR-T-005** 優先度（低 / 中 / 高 / 緊急）をバッジで色分け表示する
- **FR-T-006** 新規タスクをモーダルダイアログから作成できる
- **FR-T-007** タスクカードのメニューから編集・削除ができる

#### 3.1.2 タスクの属性

| 属性 | 型 | 必須 | 説明 |
|------|----|------|------|
| タイトル | 文字列 | ✓ | タスク名（1文字以上） |
| 説明 | 文字列 | - | 詳細説明 |
| ステータス | Enum | ✓ | todo / in_progress / in_review / done |
| 優先度 | Enum | ✓ | low / medium / high / urgent |
| 期限 | 日付 | - | YYYY-MM-DD形式 |
| 担当者 | メンバーID | - | チームメンバーとの紐付け |
| タグ | 文字列配列 | - | 複数タグ付け可能 |

---

### 3.2 ユーザー管理

- **FR-M-001** チームメンバーの一覧を表示する（名前・役職・メールアドレス・担当タスク数）
- **FR-M-002** 新規メンバーをダイアログから登録できる（名前・メール・役職・アバターカラー）
- **FR-M-003** 既存メンバーの情報を編集できる
- **FR-M-004** メンバーを削除できる（削除前に確認ダイアログを表示する）
- **FR-M-005** 各メンバーカードに担当タスク数（全件 / 進行中 / 完了）を表示する

#### 3.2.1 メンバーの属性

| 属性 | 型 | 必須 | 説明 |
|------|----|------|------|
| 名前 | 文字列 | ✓ | 氏名（1文字以上） |
| メールアドレス | 文字列 | ✓ | メール形式 / 一意 |
| 役職 | 文字列 | ✓ | チーム内の役割 |
| アバターカラー | 文字列 | ✓ | HEXカラーコード（未指定時はランダム） |

---

### 3.3 チーム負荷ビュー

- **FR-W-001** メンバーごとのタスク件数（ステータス別）を一覧で表示する
- **FR-W-002** 期限切れタスクがあるメンバーを警告アイコンで強調する
- **FR-W-003** 担当タスクのないメンバーも一覧に表示する

---

### 3.4 今後のタスクビュー

- **FR-U-001** 未完了タスクを期限日の昇順で一覧表示する
- **FR-U-002** 期限切れ・本日期限・今週期限のタスクをラベルで区別する
- **FR-U-003** 表示件数の上限を指定できる（デフォルト：10件、最大：50件）

---

### 3.5 ダッシュボード（ベロシティ分析）

- **FR-D-001** 以下のKPIカードを表示する
  - 週平均ベロシティ（直近8週間の完了タスク数の平均）
  - 期間内完了タスク数
  - 平均サイクルタイム（作成から完了までの日数）
  - 完了率（期間内完了 ÷ 期間内新規）
- **FR-D-002** 直近8週間の週次ベロシティ（完了数・新規数）を棒グラフ＋折れ線グラフで表示する
- **FR-D-003** ステータス別タスク件数を円グラフで表示する
- **FR-D-004** 優先度別タスク件数を横棒グラフで表示する
- **FR-D-005** 担当者別ワークロード上位5名を進捗バーで表示する

---

## 4. 非機能要件

### 4.1 UI / UX

- **NFR-UI-001** 全画面テキストは日本語で表示する
- **NFR-UI-002** レスポンシブレイアウト対応（最小幅：768px）
- **NFR-UI-003** 操作の成功・失敗はトースト通知で明示する
- **NFR-UI-004** データ取得中はスケルトンローダーを表示する

### 4.2 パフォーマンス

- **NFR-P-001** APIレスポンスタイムは通常時 500ms 以内とする
- **NFR-P-002** TanStack Queryによるクライアントサイドキャッシュを活用し、不要な再取得を抑制する

### 4.3 データ整合性

- **NFR-D-001** APIのリクエスト・レスポンスはZodスキーマでバリデーションを行う
- **NFR-D-002** タスクのステータス変更時は関連するキャッシュ（サマリー・ワークロード等）を即時無効化する

## 5. APIエンドポイント一覧

|---------|------|------|
| GET | /api/healthz | ヘルスチェック |
| GET | /api/members | メンバー一覧取得 |
| POST | /api/members | メンバー作成 |
| PATCH | /api/members/:id | メンバー更新 |
| DELETE | /api/members/:id | メンバー削除 |
| GET | /api/tasks | タスク一覧取得（フィルタ可） |
| POST | /api/tasks | タスク作成 |
| GET | /api/tasks/:id | タスク取得 |
| PATCH | /api/tasks/:id | タスク更新 |
| DELETE | /api/tasks/:id | タスク削除 |
| GET | /api/stats/summary | タスクサマリー統計 |
| GET | /api/stats/upcoming | 直近の期限タスク一覧 |
| GET | /api/stats/workload | メンバー別ワークロード |
| GET | /api/stats/velocity | 週次ベロシティレポート |
